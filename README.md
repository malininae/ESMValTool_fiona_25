# This is a branch specific README

This is code used for creating the figures for Malinina et al. (2025) "Attribution of extreme winds during 2022 post-tropical cyclone Fiona in Atlantic Canada".

The original README is saved in `original_README.md`. Please use `used_environment.yml` to recreate the environment, the original ESMValTool environment can be found in the `original_environment.yml`. 

The information on how to install and use ESMValTool can be found [here](https://docs.esmvaltool.org/en/latest/).
